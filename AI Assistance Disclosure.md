# AI Assistance Disclosure

## Summary

Artificial intelligence tools were used to assist with the design, drafting, implementation, debugging, and documentation of this project. The project owner directed the requirements, tested the program, identified failures and desired changes, and made the decision to publish the resulting work.

## Areas of AI assistance

AI assistance contributed to:

- drafting and revising HTML, CSS, and JavaScript;
- proposing interface and accessibility options;
- implementing document segmentation, editing, tracked modification notes, basic DOCX text extraction, and browser text-to-speech controls;
- identifying and correcting JavaScript errors;
- generating an application icon;
- drafting the README and this disclosure document.

## Human contribution and oversight

The project owner supplied the original concept and functional requirements, evaluated working versions, reported incorrect behaviour, selected the MIT Licence, and requested subsequent features. AI-generated material was used as development assistance rather than accepted as an independent authority. Users and contributors should still review, test, and validate the implementation for their own environment and accessibility requirements.

## Generated visual asset

The book-and-speaker icon was generated with Microsoft Copilot and then cropped, resized, and embedded in the standalone editor. The separate PNG is provided for repository presentation and possible reuse within this project.

## Technical limitations

AI-assisted code can contain defects, security issues, accessibility problems, compatibility limitations, or incomplete assumptions. The software is provided under the MIT Licence without warranty. DOCX import is intentionally limited to basic text extraction, and speech behaviour depends on browser and operating-system capabilities.

## Privacy statement

The current program is designed to process documents locally in browser memory and contains no analytics or document-upload service. Browser speech synthesis may use local or remote voices depending on the selected voice and platform. Users requiring local processing should choose a voice identified by the browser as local.
